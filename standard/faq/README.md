# ❓ Частые вопросы по Standard

## Как выбрать сборочные файлы?

Выберите [4 или 6 индикаторов](../assembly/README.md), затем вариант монтажа и ориентацию индикаторов. Во всех документах должен быть выбран одинаковый вариант.

## Где инструкция по сборке?

В [разделе инструкций](../manuals/README.md) опубликованы PDF для Standard на 4 и на 6 индикаторов.

## Где прошивка для моей платы?

Готовые сборки пока отсутствуют. Откройте [совместимость и настройку Standard](../firmware/README.md).

## Как проверить ошибку или неправильные цифры?

Используйте [диагностику по симптомам](../../common/troubleshooting/README.md) и [таблицу кодов ошибок](../../common/manuals/USER_GUIDE.md#коды-ошибок).

Другие ответы и список данных для обращения за помощью — в [общем FAQ](../../FAQ.md).
