# ⚙️ Прошивка Standard: совместимость и настройка

> [!NOTE]
> Готовые сборки и архивы прошивок для Standard в этой папке пока не опубликованы. Доступна документация по настройке внешней прошивки.

В документации проекта используется [radon-lab/NixieClock](https://github.com/radon-lab/NixieClock) с параметрами под разводку DIY_Alliance.

## Перед загрузкой

Сверьте:

- линейку **Standard**, количество индикаторов **4 / 6** и ревизию платы;
- вариант сборки и установленную периферию;
- подключение пинов по схеме своей платы;
- катодную маску и порядок анодов выбранных индикаторов.

Количество индикаторов само по себе не определяет совместимость прошивки.

## Порядок действий

1. Откройте [BOM и схему своей платы](../assembly/README.md).
2. Прочитайте [общие пояснения по прошивке](../../common/firmware/README.md).
3. Выполните [настройку и загрузку](../../common/firmware/CONFIGURATION.md).
4. Проверьте цифры и порядок индикаторов; при проблемах используйте [диагностику](../../common/troubleshooting/README.md).
