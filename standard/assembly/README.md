# Assembly

Материалы для сборки Standard Edition разделены по количеству индикаторов.

## Версии плат

| Версия платы | Назначение |
| --- | --- |
| [Standard Boards x4 Tubes](standard-boards-x4-tubes/) | Версия Standard для 4 индикаторов |
| [Standard Boards x6 Tubes](standard-boards-x6-tubes/) | Версия Standard для 6 индикаторов |

## Что лежит внутри каждой версии

| Папка | Что хранится |
| --- | --- |
| `bom/` | Списки компонентов для выбранной версии платы |
| `export-step/` | STEP и PARASOLID 3D-модели платы |
| `pcb-3d-print/` | 3D-представления печатной платы и собранных вариантов |
| `pcb-print/` | Печатные сборочные чертежи платы |
| `pdf3d/` | 3D PDF и похожие интерактивные материалы для визуальной проверки платы |
| `schematic-print/` | Печатные версии электрических схем |
