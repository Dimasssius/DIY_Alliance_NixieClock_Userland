# 🧩 Материалы сборки Standard

Выберите число индикаторов. На странице платы есть таблица файлов по монтажу и ориентации индикаторов.

| Плата | Куда перейти |
| :--- | :--- |
| Standard · 4 индикатора | [BOM, схемы и чертежи](standard-boards-x4-tubes/README.md) |
| Standard · 6 индикаторов | [BOM, схемы и чертежи](standard-boards-x6-tubes/README.md) |

## Что открыть перед сборкой

1. **BOM** — чтобы подобрать компоненты и проверить номиналы.
2. **Электрическую схему** — чтобы сверить соединения и обозначения.
3. **Сборочный чертёж** — чтобы проверить расположение компонентов.
4. **Рендер платы** — для визуальной проверки монтажа.

Для Standard используйте документы одного варианта: выводной или поверхностный монтаж, вертикальные или горизонтальные индикаторы.
