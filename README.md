# Nixie Clock PCB

Open-source hardware files, documentation and assembly materials for Nixie tube clocks.

Проект содержит печатные платы, схемы, BOM, Gerber-файлы, 3D-модели и инструкции для сборки часов на газоразрядных индикаторах.

## Линейки проекта

### Standart Edition

Базовая линейка печатных плат для сборки часов на ГРИ.

Подходит для:
- новичков;
- самостоятельной сборки;
- изучения принципов работы часов на газоразрядных индикаторах;
- сборки часов на 4 или 6 индикаторов.

Возможные варианты:
- DIP-компоненты;
- SMD-компоненты;
- смешанная сборка DIP + SMD.

### Hardcore Edition

Платы повышенной сложности с расширенным функционалом.

Рекомендуется для людей с опытом пайки SMD-компонентов и чтения электрических схем.

Особенности:
- компактная схемотехника;
- большое количество SMD-компонентов;
- поддержка дополнительных модулей;
- web-интерфейс;
- Wi-Fi-настройка;
- подключение датчиков;
- поддержка разделительных неоновых точек.
