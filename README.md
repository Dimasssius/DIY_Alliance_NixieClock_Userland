## 📖 О проекте

Профессиональный проект часов на газоразрядных индикаторах (ГРИ) с открытым исходным кодом. Разработан с учетом современных требований к качеству, надежности и эстетике. Проект включает **полную документацию**, **готовые файлы для производства** и **подробные инструкции** по сборке.

### ✨ Ключевые особенности

- 🔧 **Две версии плат** — выберите подходящий вариант под ваш уровень
- 📐 **Готовые Gerber-файлы** — заказывайте платы в любой fab-лаборатории
- 🎨 **3D-модели корпусов** — файлы для печати на 3D-принтере
- 📚 **Подробная документация** — от схемы до финальной сборки
- 🔄 **Регулярные обновления** — исправления и улучшения

| Категория | Файлы | Описание |
|-----------|-------|----------|

## ⚙️ Технические характеристики

| Параметр | Значение |
|----------|----------|
| **Микроконтроллер** | ATmega328P / ATmega8 |
| **Индикаторы** | IN-12, IN-14, Z568M (совместимы) |
| **Питание** | 5V DC (USB / microUSB) |
| **Высокое напряжение** | ~170V (преобразователь) |
| **Точность хода** | ±1 сек/сутки (с RTC) |
| **Дополнительно** | Коррекция хода, будильник, индикация температуры |
