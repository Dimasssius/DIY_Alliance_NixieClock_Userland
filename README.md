## Важно

В репозитории **не публикуются**:

- исходники печатных плат;
- Gerber-файлы для производства плат;
- файлы трассировки и производственные проекты PCB.

Репозиторий является базой полезных файлов для пользователей готовых плат: документация, схемы, BOM, прошивки, изображения, 3D-модели, инструкции и материалы по решению типовых проблем.

## Быстрый старт

1. Откройте [START_HERE.md](START_HERE.md).
2. Выберите свою линейку платы: `standard/` или `hardcore/`.
3. Найдите инструкцию по сборке в папке `manuals/`.
4. Проверьте BOM и схемы перед монтажом.
5. Используйте прошивку из папки `firmware/` только для подходящей версии платы.
6. При проблемах откройте [FAQ.md](FAQ.md) и раздел `troubleshooting/`.

Для владельцев плат доступны:

## Линейки плат

| Линейка | Назначение |
| --- | --- |
| Standard Edition | Базовая версия для большинства пользователей и первой самостоятельной сборки |
| Hardcore Edition | Продвинутая версия с расширенным функционалом |

## Standard Edition

Раздел: [`standard/`](standard/)

Подходит для большинства пользователей и первой самостоятельной сборки.

Возможные материалы:

- `firmware/` - прошивки;
- `bom/` - списки компонентов;
- `schematics/` - электрические схемы;
- `manuals/` - инструкции и руководства;
- `photos/` - фотографии плат и сборки;
- `renders/` - рендеры;
- `3d-models/` - 3D-модели;
- `faq/` - вопросы и ответы по Standard Edition.

## Hardcore Edition

Раздел: [`hardcore/`](hardcore/)

Предназначена для опытных пользователей и расширенных вариантов сборки.

Hardcore Edition разделяется на две версии по количеству индикаторов:

| Версия платы | Назначение |
| --- | --- |
| [x4 SMD](hardcore/assembly/x4-smd/) | Версия Hardcore для 4 индикаторов |
| [x6 SMD](hardcore/assembly/x6-smd/) | Версия Hardcore для 6 индикаторов |

Внутри каждой версии платы есть три комплектации:

| Комплектация | Назначение |
| --- | --- |
| Minimal Configuration | Минимальная комплектация компонентов, необходимая для запуска часов |
| Base Configuration | Стандартная комплектация с реализацией всех основных функций часов |
| Maximal Configuration | Максимальная комплектация с добавлением датчиков температуры, IR-приемника и других опций |

Возможные материалы:

- `firmware/` - прошивки;
- `bom/` - списки компонентов;
- `schematics/` - электрические схемы;
- `manuals/` - инструкции и руководства;
- `photos/` - фотографии плат и сборки;
- `renders/` - рендеры;
- `3d-models/` - 3D-модели;
- `faq/` - вопросы и ответы по Hardcore Edition.

## Безопасность

Часы на газоразрядных индикаторах могут использовать высокое напряжение. Перед сборкой, прошивкой и настройкой внимательно изучите инструкцию, схему и рекомендации по безопасности.

Материалы проекта предназначены для пользователей, которые понимают риски работы с электроникой и высоким напряжением.
