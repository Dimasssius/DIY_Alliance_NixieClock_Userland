# 🚀 О проекте

Этот репозиторий является централизованным хранилищем файлов проекта **Nixie Clock PCB**.

Здесь собраны все материалы, необходимые для самостоятельного изготовления часов на газоразрядных индикаторах:

✅ Gerber-файлы для производства плат

✅ Электрические принципиальные схемы

✅ BOM (списки компонентов)

✅ Pick & Place файлы

✅ PDF-файлы для проверки производства

✅ 3D-модели

✅ Инструкции по сборке

✅ Материалы по настройке прошивки

---

# 📦 Линейки плат

Проект состоит из двух независимых продуктовых линеек.

| Серия | Назначение |
|---------|---------|
| 🔹 Standard Edition | Универсальные платы для большинства пользователей |
| 🔥 Hardcore Edition | Продвинутые платы для опытных разработчиков |

---

# 🔹 Standard Edition

Платы серии Standard предназначены для максимально простой сборки часов.

### Основные особенности

- ✅ версии на 4 и 6 индикаторов
- ✅ DIP-компоненты
- ✅ SMD-компоненты
- ✅ смешанная сборка
- ✅ подробная инструкция
- ✅ удобное обслуживание
- ✅ подходит для новичков

---

# 🔥 Hardcore Edition

Платы серии Hardcore предназначены для пользователей с опытом пайки и самостоятельной отладки электронных устройств.

### Основные особенности

- ⚡ встроенный повышающий преобразователь
- 🌐 WEB-интерфейс управления
- 📶 поддержка Wi-Fi
- 🌡️ подключение датчиков
- 🔧 расширенный функционал прошивки
- 📐 компактная компоновка
- 🚀 высокая степень интеграции
