# Часы на газоразрядных индикаторах (ГРИ)

![Версия](https://img.shields.io/badge/версия-2.0-blue)
![Платы](https://img.shields.io/badge/платы-Standard|Hardcore-orange)
![Лицензия](https://img.shields.io/badge/лицензия-MIT-green)

Этот репозиторий содержит полную документацию, прошивки, схемы и 3D-модели для создания часов на **газоразрядных индикаторах (ГРИ)**.

Проект разделён на **два типа печатных плат**:

- **Стандартные платы** — базовый вариант, подходит для большинства сборок.
- **Платы Hardcore** — улучшенная версия с повышенной надёжностью и дополнительными возможностями.

---

## 📁 Структура репозитория

Ветки репозитория:

| Ветка | Описание |
|-------|----------|
| `standard` | Все материалы для стандартных плат (DIP и SMD) |
| `hardcore` | Все материалы для плат Hardcore (SMD) |

Каждая ветка содержит свою собственную документацию, прошивки и схемы.

---
