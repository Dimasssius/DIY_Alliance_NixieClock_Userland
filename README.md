# Часы на газоразрядных индикаторах (ГРИ / Nixie)

> Профессиональный opensource-проект создания часов на газоразрядных индикаторах с двумя вариантами печатных плат.

![Nixie Clock Banner](https://via.placeholder.com/1000x200?text=Nixie+Clock+Project)

## О проекте

Проект посвящён разработке и сборке часов на **газоразрядных индикаторах** (ГРИ, Nixie tubes).  
В репозитории представлены две независимые линейки печатных плат:

- **Standard** — классическое решение для большинства сборщиков
- **Hardcore** — продвинутый вариант с расширенными возможностями

Каждая ветка содержит полную документацию: прошивки, схемы, 3D-модели, инструкции и известные проблемы.

## Ветки репозитория

### 🔹 [Ветка Standard](https://github.com/твой-аккаунт/твой-репозиторий/tree/standard)  
Платы для часов на ГРИ (DIP и SMD версии).  
Подходит для начинающих и опытных радиолюбителей.  
→ [Перейти в ветку Standard](https://github.com/твой-аккаунт/твой-репозиторий/tree/standard)

### 🔸 [Ветка Hardcore](https://github.com/твой-аккаунт/твой-репозиторий/tree/hardcore)  
Продвинутые платы Hardcore (только SMD).  
Оптимизированы для компактного монтажа и максимальной надёжности.  
→ [Перейти в ветку Hardcore](https://github.com/твой-аккаунт/твой-репозиторий/tree/hardcore)

## Содержание проекта (общее)

- 🕹️ Прошивки (AVRdude)
- 📐 3D-модели корпусов
- 📄 Карточки товара
- 📏 Файлы с размерами плат
- 🧾 Инструкции по сборке
- ⚡ Электрические схемы и ВОМ
- 🐞 Известные проблемы и их решение

## Инструменты

- Программатор: **AVRdude**
- MCU: ATmega (в зависимости от платы)
- Индикаторы: ГРИ (IN-14, IN-18 и аналоги)

## Как использовать

1. Выбери нужную ветку (Standard / Hardcore)
2. Скачай прошивку и схемы
3. Ориентируйся на инструкции по сборке
4. При проблемах — смотри раздел «Известные проблемы»
