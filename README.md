## О проекте

Современная интерпретация классических часов на газоразрядных индикаторах. Проект сочетает ретро-эстетику с современными технологиями и открытой архитектурой.

> **Примечание:** Файлы для производства печатных плат не публикуются. Готовые платы изготавливаются автором и доступны для заказа. Вся остальная документация — схемы, прошивки, 3D-модели — полностью открыта.

---

## Возможности

**Точное время**  
Аппаратный RTC-модуль DS3231 с сохранением настроек при отключении питания

**RGB-подсветка**  
Настраиваемая подсветка индикаторов: статичный цвет, плавные переходы, динамические эффекты

**Температура**  
Встроенный датчик DS18B20 для мониторинга температуры окружающей среды

**Будильник**  
Программируемый будильник с визуальной индикацией

**Стабильное питание**  
DC-DC преобразователь с защитой от короткого замыкания (~170В)

## Версии проекта

### Standard

*Для тех, кто ценит простоту и надежность*

- Гибридный монтаж (DIP + SMD компоненты)
- Пайка обычным паяльником
- 3D-модель корпуса в комплекте
- Размер платы: 120 × 80 мм

[Документация Standard →](standard)

### Hardcore

*Минимализм и компактность для профессионалов*

- Полностью SMD исполнение
- Компактный размер: 70 × 50 мм
- Требует навыков SMD-монтажа
- Минималистичный дизайн без корпуса

[Документация Hardcore →](hardcore)
