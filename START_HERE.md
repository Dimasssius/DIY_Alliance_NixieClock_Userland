# Start Here

Этот файл поможет быстро найти нужные материалы для вашей версии платы.

## 1. Определите линейку платы

- Standard Edition: материалы находятся в папке [`standard/`](standard/).
- Hardcore Edition: материалы находятся в папке [`hardcore/`](hardcore/).

## 2. Проверьте документы перед сборкой

Перед монтажом рекомендуется открыть:

- `manuals/` - инструкция по сборке и настройке;
- [`common/manuals/`](common/manuals/) - общее руководство по эксплуатации и управлению кнопками;
- `assembly/` - BOM, схемы, изображения плат и 3D-материалы;
- `firmware/` - прошивки и заметки по совместимости;
- `troubleshooting/` - типовые проблемы и диагностика.

## 3. Прошивка

Сейчас в часах используется прошивка [radon-lab/NixieClock](https://github.com/radon-lab/NixieClock) с настройками под разводку плат DIY_Alliance.

Общие заметки по адаптации прошивки находятся в [`common/firmware/`](common/firmware/).

Используйте только прошивку и настройки, которые соответствуют вашей версии платы, количеству индикаторов и комплектации.

## 4. Если что-то не работает

Откройте [FAQ.md](FAQ.md), затем раздел [`troubleshooting/`](troubleshooting/).

## 5. Важно

Gerber-файлы, исходники печатных плат и производственные проекты PCB в этом репозитории не публикуются.
