# Start Here

Этот файл поможет быстро найти нужные материалы для вашей версии платы.

## 1. Определите линейку платы

- Standard Edition: материалы находятся в папке [`standard/`](standard/).
- Hardcore Edition: материалы находятся в папке [`hardcore/`](hardcore/).

## 2. Проверьте документы перед сборкой

Перед монтажом рекомендуется открыть:

- `manuals/` - инструкция по сборке и настройке;
- `bom/` - список компонентов;
- `schematics/` - электрическая схема;
- `photos/` - фотографии для сверки сборки.

## 3. Прошивка

Прошивки находятся в папке `firmware/` внутри выбранной линейки платы.

Используйте только прошивку, которая соответствует вашей версии платы.

## 4. Если что-то не работает

Откройте [FAQ.md](FAQ.md), затем раздел [`troubleshooting/`](troubleshooting/).

## 5. Важно

Gerber-файлы, исходники печатных плат и производственные проекты PCB в этом репозитории не публикуются.
