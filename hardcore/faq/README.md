# Частые вопросы по Hardcore

## Как выбрать сборочные файлы?

Выберите [4 или 6 индикаторов](../assembly/README.md), затем комплектацию **Minimal / Base / Maximal**. Используйте BOM, схему и чертёж одной комплектации.

## Где инструкция по сборке?

Отдельная пошаговая инструкция Hardcore пока не опубликована. В [разделе инструкций](../manuals/README.md) собраны доступные общие руководства и ссылки на материалы комплектаций.

## Где прошивка для моей платы?

Готовые сборки пока отсутствуют. Откройте [совместимость и настройку Hardcore](../firmware/README.md).

## Как проверить ошибку или неправильные цифры?

Используйте [диагностику по симптомам](../../common/troubleshooting/README.md) и [таблицу кодов ошибок](../../common/manuals/USER_GUIDE.md#коды-ошибок).

Другие ответы и список данных для обращения за помощью — в [общем FAQ](../../FAQ.md).
