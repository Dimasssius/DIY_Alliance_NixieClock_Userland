# 🧩 Материалы сборки Hardcore

Выберите число индикаторов, затем комплектацию.

| Плата | Куда перейти |
| :--- | :--- |
| Hardcore · 4 индикатора | [Комплектации и документы](hardcore-boards-x4-tubes/README.md) |
| Hardcore · 6 индикаторов | [Комплектации и документы](hardcore-boards-x6-tubes/README.md) |

## Что открыть перед сборкой

1. **BOM** — чтобы подобрать компоненты и проверить номиналы.
2. **Электрическую схему** — чтобы сверить соединения и обозначения.
3. **Сборочный чертёж** — чтобы проверить расположение компонентов.
4. **Рендер платы** — для визуальной проверки монтажа.

Для Hardcore доступны Minimal, Base и Maximal. Используйте документы одной комплектации.
