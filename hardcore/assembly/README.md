# Assembly

Материалы для сборки Hardcore Edition разделены по количеству индикаторов и комплектациям.

## Версии плат

| Версия платы | Назначение |
| --- | --- |
| [x4 SMD](x4-smd/) | Версия Hardcore для 4 индикаторов |
| [x6 SMD](x6-smd/) | Версия Hardcore для 6 индикаторов |

## Комплектации внутри каждой версии

| Комплектация | Назначение |
| --- | --- |
| `minimal-configuration/` | Минимальная комплектация компонентов, необходимая для запуска часов |
| `base-configuration/` | Стандартная комплектация с реализацией всех основных функций часов |
| `maximal-configuration/` | Максимальная комплектация с дополнительными датчиками и модулями: температура, IR-приемник и другие опции |

## Что лежит внутри каждой комплектации

| Папка | Что хранится |
| --- | --- |
| `pdf3d/` | 3D PDF и похожие интерактивные материалы для визуальной проверки платы |
| `schematic-print/` | Печатные версии электрических схем |
| `pcb-3d-print/` | 3D-представления печатной платы |
| `pcb-print/` | Печатные изображения платы для проверки монтажа и расположения компонентов |
| `bom/` | Списки компонентов для выбранной версии платы и комплектации |
| `report-board-stack/` | Отчеты по стеку платы |
| `pick-place/` | Pick and place файлы, если они разрешены к публикации |
