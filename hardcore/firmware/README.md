# Firmware

Прошивки и заметки по совместимости для плат Hardcore Edition.

Сейчас в часах используется прошивка [radon-lab/NixieClock](https://github.com/radon-lab/NixieClock) с настройками под разводку плат DIY_Alliance.

Общая информация по адаптации прошивки находится в [common/firmware](../../common/firmware/).

## Важно

- Используйте только прошивку и настройки, которые соответствуют вашей версии платы Hardcore.
- Для версий x4 и x6, а также для комплектаций Minimal, Base и Maximal могут отличаться пины и подключенная периферия.
- Перед прошивкой сверяйте версию платы, комплектацию, BOM и схему.

Готовые файлы прошивок, архивы релизов и инструкции по обновлению можно размещать в этой папке.
