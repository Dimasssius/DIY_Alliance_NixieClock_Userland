# Hardcore Edition

Материалы для плат DIY_Alliance Nixie Clock Hardcore Edition.

Этот раздел предназначен для расширенной версии платы: прошивки, схемы, BOM, инструкции, даташиты, фотографии, рендеры, 3D-модели и ответы на частые вопросы.

## Комплектации

| Комплектация | Назначение |
| --- | --- |
| [Minimal Configuration](assembly/minimal-configuration/) | Минимальная комплектация компонентов, необходимая для запуска часов |
| [Base Configuration](assembly/base-configuration/) | Стандартная комплектация с реализацией всех основных функций часов |
| [Maximal Configuration](assembly/maximal-configuration/) | Максимальная комплектация с дополнительными датчиками и модулями: температура, IR-приемник и другие опции |

Все материалы по комплектациям лежат в папке [assembly](assembly/).

Внутри каждой комплектации используются одинаковые разделы с файлами для сборки и проверки:

- `pdf3d/` - 3D PDF и похожие интерактивные материалы;
- `schematic-print/` - печатные версии схем;
- `pcb-3d-print/` - 3D-представления печатной платы;
- `pcb-print/` - печатные изображения платы;
- `bom/` - список компонентов;
- `report-board-stack/` - отчеты по стеку платы;
- `pick-place/` - pick and place файлы, если они разрешены к публикации.
