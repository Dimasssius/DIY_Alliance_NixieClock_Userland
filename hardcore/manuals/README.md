# Инструкции Hardcore

> [!NOTE]
> Отдельная пошаговая инструкция по сборке Hardcore пока не опубликована. Доступны общие рекомендации и материалы каждой комплектации.

## Документы вашей сборки

Выберите количество индикаторов, затем комплектацию **Minimal / Base / Maximal**:

| Плата | Выбор комплектации и документов |
| --- | --- |
| Hardcore · 4 индикатора | [Открыть материалы](../assembly/hardcore-boards-x4-tubes/README.md) |
| Hardcore · 6 индикаторов | [Открыть материалы](../assembly/hardcore-boards-x6-tubes/README.md) |

В выбранной комплектации откройте BOM, электрическую схему и сборочный чертёж. Расположение компонентов и подключение периферии проверяйте по документам Hardcore.
