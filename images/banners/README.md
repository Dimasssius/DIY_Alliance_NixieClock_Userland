## Правила оформления

- На одной странице достаточно одной обложки. В каталогах отдельных файлов используются компактный заголовок и контекст платы.
- Эмодзи обозначают раздел или действие. Текст подписи всегда сохраняется; длинные таблицы не заполняются декоративными значками.
- Основной текст и длинные описания выравниваются слева. Форматы файлов, коды, номера и превью — по центру.
- Заголовки технических разделов сохраняются, чтобы не ломать ссылки на настройку, диагностику и коды ошибок.
- Изображения содержат понятный `alt`. Обложка адаптируется по ширине через `width="100%"`.
- В README используются возможности GitHub Markdown: заголовки, таблицы, ссылки, предупреждения и раскрываемые примечания.
- Принудительная ширина таблиц через CSS недоступна в репозитории GitHub. Не добавляйте пустые изображения и пробелы для растягивания.

Ограничения платформы: [GitHub Markup](https://github.com/github/markup), [стили таблиц Primer](https://github.com/primer/css/blob/main/src/markdown/tables.scss).
