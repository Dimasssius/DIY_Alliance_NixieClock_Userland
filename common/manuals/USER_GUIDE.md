# User Guide

Краткая структурированная выжимка из PDF-руководства по эксплуатации. Информация актуальна для всех видов и типов плат DIY_Alliance Nixie Clock.

## Кнопки

На часах используется три основные кнопки и одна дополнительная функциональная кнопка.

| Кнопка | Назначение |
| --- | --- |
| Правая | Просмотр даты, увеличение значений, выбор некоторых режимов |
| Средняя | Вход в меню, выбор пункта, подтверждение |
| Левая | Просмотр температуры, уменьшение значений, выбор некоторых режимов |
| Дополнительная | Таймер, секундомер, будильник и отдельные функции, если кнопка установлена |

Для базового управления обязательно нужны три основные кнопки. Дополнительная кнопка используется только если она предусмотрена сборкой.

## Режим часов: стандартное управление

| Действие | Результат |
| --- | --- |
| Клик правой кнопки | Показ текущей даты, повторный клик переключает дата/год |
| Клик левой кнопки | Показ температуры, повторные клики переключают температуру, давление и влажность |
| Клик средней кнопки | Быстрое меню подсветки, секундных точек и анимации смены минут |

В быстром меню:

| Кнопка | Что переключает |
| --- | --- |
| Левая | Режим светодиодной подсветки |
| Средняя | Режим анимации разделительных точек |
| Правая | Режим анимации смены минут |
| Дополнительная | Режим анимации смены секунд |

Если дополнительной кнопки нет, удержание правой кнопки во время отображения режима анимации минут переводит к выбору анимации секунд.

## Режим часов: упрощенное управление

| Действие | Результат |
| --- | --- |
| Клик правой кнопки | Переключение режима разделительных точек |
| Клик средней кнопки | Переключение анимации смены минут |
| Удержание средней кнопки | Переключение анимации смены секунд |
| Клик левой кнопки | Переключение режима подсветки |

| Номер | Режим |

| 1 | Статичная |
| 2 | Дыхание |
| 3 | Дыхание со сменой цвета |
| 4 | Бегущий огонь |
| 5 | Бегущий огонь со сменой цвета |
| 6 | Бегущий огонь с радугой |
| 7 | Бегущий огонь с конфетти |
| 8 | Волна |
| 9 | Волна со сменой цвета |
| 10 | Волна с радугой |
| 11 | Волна с конфетти |

Удержание левой кнопки во время отображения режима подсветки переводит к выбору цвета. Это работает только в режимах, где поддерживается смена цвета: статичная, дыхание, бегущий огонь и волна.

## Настройка времени

Для входа в настройку времени удерживайте правую кнопку.

| Действие | Результат |
| --- | --- |
| Клик средней кнопки | Переключение настраиваемого поля: часы/минуты, месяц/дата, год |
| Левая кнопка | Уменьшить значение |
| Правая кнопка | Увеличить значение |
| Удержание средней кнопки | Возврат в режим часов |

## Основные настройки

В стандартном режиме удержание средней кнопки открывает меню основных настроек.

| Действие | Результат |
| --- | --- |
| Клик средней кнопки | Вход в подпункт или возврат к выбору пункта |
| Левая/правая кнопка | Выбор пункта меню или изменение значения |
| Удержание средней кнопки | Возврат в режим часов |
| Удержание левой/правой кнопки | Выбор подпункта меню |

Пункты меню:

| Номер | Настройка |
| --- | --- |
| 01 | Формат времени: 12ч или 24ч |
| 02 | Глюки: выключены или включены |
| 03 | Звук кнопок: выключен или включен |
| 04 | Время звука смены часа: начало и конец |
| 05 | Время смены подсветки: ночь и день |
| 06 | Яркость индикаторов: ночь и день |
| 07 | Яркость подсветки: ночь и день |
| 08 | Яркость секундных точек: ночь и день |
| 09 | Коррекция датчика температуры |
| 10 | Интервал и анимация автоматического отображения |
| 11 | Интервал и анимация антиотравления индикаторов |
| 12 | Время ожидания после выхода из сна |

## Таймер и секундомер

Для включения таймера или секундомера нажмите дополнительную кнопку.

| Действие | Результат |
| --- | --- |
| Клик дополнительной кнопки | Пуск/пауза |
| Клик средней кнопки | Настройка таймера, только в режиме таймера |
| Клик или удержание левой кнопки | Режим секундомера |
| Клик или удержание правой кнопки | Режим таймера |
| Удержание дополнительной кнопки | Сброс таймера/секундомера |
| Удержание средней кнопки | Возврат к режиму часов |

При возврате к часам таймер продолжает работать в фоне, а секундомер ставится на паузу.

Настройка таймера:

| Действие | Результат |
| --- | --- |
| Клик средней кнопки | Переключение разрядов `ММ:СС`, максимум `99:59` |
| Левая кнопка | Уменьшить значение |
| Правая кнопка | Увеличить значение |
| Удержание средней или дополнительной кнопки | Выход к таймеру |

## Будильник

Для входа в меню настройки будильника удерживайте левую кнопку.

| Действие | Результат |
| --- | --- |
| Клик средней кнопки | Перемещение по индикаторам |
| Левая/правая кнопка | Уменьшить или увеличить значение |
| Удержание левой/правой кнопки | Смена поля настройки: часы/минуты, режим |
| Удержание средней кнопки | Возврат к режиму часов |

Режимы будильника:

| Номер | Режим |
| --- | --- |
| 01 | Однократный |
| 02 | Каждый день |
| 03 | По будням |
| 04 | Выбор по дням недели |

Во время тревоги будильника:

| Действие | Результат |
| --- | --- |
| Клик любой кнопки | Отложить будильник на установленный тайм-аут |
| Удержание любой кнопки | Отключить будильник. Для однократного режима отключает насовсем |

Если будильник был отложен, удержание средней или дополнительной кнопки в режиме часов отключает будильник.

## Коды ошибок

Если при старте часов звучит длинный писк и отображается код, используйте таблицу ниже.

| Код | Значение |
| --- | --- |
| 0001 | Нет связи с модулем DS3231: модуль неисправен или есть проблемы с шиной I2C |
| 0002 | Сбой осциллятора DS3231: батарейка модуля разряжена или есть проблемы с тактированием |
| 0003 | Слишком короткий сигнал SQW: помехи или неверный сигнал на SQW |
| 0004 | Слишком длинный сигнал SQW: сигнал пропал или отсутствовал при запуске |
| 0005 | Выбранный датчик температуры не обнаружен |
| 0006 | Слишком низкое или слишком высокое напряжение питания |
| 0007 | Сбой памяти EEPROM |
| 0008 | Программная перезагрузка: нестабильность программы или проблемы с микроконтроллером |
| 0009 | Сбой работы преобразователя |
| 0010 | Переполнение заполнения ШИМ преобразователя |
| 0011 | Переполнение стека |
| 0012 | Переполнение тиков времени: основная программа не отвечает |
| 0013 | Сбой работы динамической индикации |

| --- | --- |

## Меню отладки

Меню отладки предназначено для опытных пользователей.

Управление:

| Действие | Результат |
| --- | --- |
| Клик средней кнопки | Выбор пункта отладки |
| Левая кнопка | Уменьшить значение |
| Правая кнопка | Увеличить значение |
| Удержание средней кнопки | Выход к часам |

Пункты меню отладки:

| Номер | Настройка |
| --- | --- |
| 01 | Коррекция хода часов DS3231 |
| 02 | Коррекция хода внутреннего осциллятора |
| 03 | Минимальное значение ШИМ |
| 04 | Максимальное значение ШИМ |
| 05 | Коррекция напряжения преобразователя |
| 06 | Программирование кнопок ИК-пульта, поддерживаются пульты NEC |
| 07 | Калибровка датчика освещенности |
| 08 | Сброс настроек отладки |

Калибровка датчика освещенности:

1. Войти в меню отладки удержанием левой кнопки при подаче питания.
2. Выбрать пункт `07`.
3. Поставить часы в светлое место на 1-3 секунды.
4. Поставить часы в темное место на 1-3 секунды.
5. Кликнуть средней кнопкой для выхода к выбору пунктов меню отладки.
6. Удержать среднюю кнопку для выхода из меню и сохранения настроек.
