# 🛠️ Инструменты

| Инструмент | Когда нужен | Платформа |
| :--- | :--- | :--- |
| [Подбор катодной маски](cathode-mask/README.md) | В прошивке нет маски индикатора или отображаются неправильные цифры | Windows |

Перед использованием прочитайте [порядок подбора маски](../firmware/CONFIGURATION.md#подбор-катодной-маски-индикаторов). Если цифры верны, но перепутаны позиции индикаторов, нужен [подбор порядка анодов](../firmware/CONFIGURATION.md#подбор-порядка-анодов).
