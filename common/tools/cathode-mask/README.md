# Подбор катодной маски

Утилита для Windows помогает определить порядок катодов, если в прошивке нет готовой маски для ваших индикаторов или отображаются неправильные цифры.

## Файл программы

[Открыть файл программы · EXE](<Программа для подбора катодной маски.exe>). На странице файла используйте кнопку скачивания GitHub.

## Как использовать

Общий порядок описан в [инструкции по подбору катодной маски](../../firmware/CONFIGURATION.md#подбор-катодной-маски-индикаторов). После получения маски внесите её в настройки прошивки и повторно прошейте часы.

Если цифры верны, а позиции индикаторов перепутаны, проверьте [порядок анодов](../../firmware/CONFIGURATION.md#подбор-порядка-анодов).
