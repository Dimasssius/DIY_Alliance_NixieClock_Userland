# Cathode Mask Tool

В этой папке лежит программа для подбора катодной маски индикаторов.

## Файл

- `Программа для подбора катодной маски.exe` - утилита для Windows.

## Когда использовать

Программа нужна, если в прошивке нет готовой маски под выбранные индикаторы или цифры отображаются неправильно.

Общий порядок работы описан в [Firmware Configuration](../../firmware/CONFIGURATION.md#подбор-катодной-маски-индикаторов).

## Важно

Программа предназначена только для подбора порядка катодов. После получения маски нужно внести настройки в прошивку и повторно прошить часы.
