# Поддерживаемые индикаторы

Этот раздел содержит базу поддерживаемых газоразрядных индикаторов для плат DIY_Alliance Nixie Clock.

В скобках и в отдельном столбце указаны индикаторы, совместимые по сокету и посадочному месту. Например, если плата рассчитана под ИН-12, на нее можно установить индикаторы из списка совместимых, если остальные электрические и механические параметры подходят для конкретной сборки.

## Как читать таблицы

| Поле | Значение |
| --- | --- |
| Название индикатора | Индикатор или комбинация индикаторов, под которые рассчитана плата |
| Конфигурация | Количество основных индикаторов или комбинированный вариант с секундными индикаторами |
| Совместимые индикаторы по сокету | Индикаторы, совместимые по сокету/посадочному месту |

Комбинированные варианты, например `ИН-8 + ИН-16`, означают одну плату, на которой установлены 4 основных индикатора ИН-8 и 2 дополнительных индикатора ИН-16 для секунд.
