# Common

Общие материалы для всех версий плат.

Раздел предназначен для документов, таблиц, инструкций, рекомендаций и справочных файлов, которые относятся одновременно к Standard Edition и Hardcore Edition.

## Разделы

- [firmware](firmware/) - общая информация по используемой прошивке и ее адаптации под платы DIY_Alliance.
- [manuals](manuals/) - общие руководства, актуальные для всех видов и типов плат.
