# Common

Общие материалы для всех версий плат.

Раздел предназначен для документов, таблиц, инструкций, рекомендаций, инструментов и справочных файлов, которые относятся одновременно к Standard Edition и Hardcore Edition.

## Разделы

- [firmware](firmware/) - общая информация по используемой прошивке и ее адаптации под платы DIY_Alliance.
- [indicators](indicators/) - база поддерживаемых индикаторов и совместимых посадочных мест.
- [manuals](manuals/) - общие руководства, актуальные для всех видов и типов плат.
- [tools](tools/) - утилиты и вспомогательные программы для настройки часов.
- [troubleshooting](troubleshooting/) - типовые проблемы и способы диагностики.
