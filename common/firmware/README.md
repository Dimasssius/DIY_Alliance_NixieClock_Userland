# Firmware Notes

В часах DIY_Alliance Nixie Clock сейчас используется прошивка [radon-lab/NixieClock](https://github.com/radon-lab/NixieClock).

Это внешняя прошивка автора radon-lab. В этом репозитории хранится информация по совместимости и настройке под платы DIY_Alliance, а не исходный код оригинальной прошивки.

## Документы

- [Firmware Configuration](CONFIGURATION.md) - порядок настройки прошивки, прошивки микроконтроллера, подбора катодной маски и порядка анодов.

## Текущий статус

На текущем этапе используется прошивка radon-lab/NixieClock с изменением параметров под разводку плат DIY_Alliance.

Этот вариант остается основным до получения новых печатных плат с изменениями. После проверки новых плат прошивку планируется портировать и адаптировать под обновленную аппаратную ревизию.

## Что изменяется под платы DIY_Alliance

При настройке прошивки под разводку плат DIY_Alliance меняются параметры подключения периферии:

- цифровые пины;
- аналоговые пины;
- используемые модули и периферия;
- маска дешифратора;
- порядок катодов индикаторов;
- порядок анодов индикаторов;
- тип платы в настройках прошивки.

## Основные файлы настройки

В прошивке radon-lab/NixieClock используются следующие файлы конфигурации:

| Файл | Назначение |
| --- | --- |
| `connection.h` | Пины подключения периферии |
| `userConfig.h` | Выбор используемой периферии и пользовательские настройки |
| `config.h` | Общие настройки, маска дешифратора и порядок катодов |
| `indication.h` | Порядок анодов индикаторов |
| `boards.h` | Место для собственных настроек платы, чтобы проще переносить их на новые версии прошивки |

Для плат DIY_Alliance, отличающихся от базовой разводки автора прошивки, используется `BOARD_TYPE 0`.

## Сервисные режимы

Некоторые сервисные режимы запускаются удержанием кнопки при подаче питания:

| Действие | Как запустить |
| --- | --- |
| Сброс настроек | Зажать среднюю кнопку и подать питание |
| Меню отладки | Зажать левую кнопку и подать питание |
| Тест системы / lamp test | Зажать правую кнопку и подать питание |
