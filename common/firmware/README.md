# Прошивка: источник, совместимость и настройка

> [!NOTE]
> Готовые сборки прошивок для плат DIY_Alliance в этой Wiki пока не опубликованы. Здесь описана адаптация внешней прошивки под вашу сборку.

## Что зависит от платы

Сверьте **линейку → ревизию → число индикаторов → вариант сборки → установленную периферию**. Настройки пинов, индикации и модулей проверяйте по схеме своей платы.

Общие инструкции описывают процесс настройки. Проверенный комплект конфигурационных файлов для каждой ревизии в Wiki пока не опубликован.

| Файл внешней прошивки | Назначение в документации Wiki |
| --- | --- |
| `connection.h` | Пины подключения периферии |
| `userConfig.h` | Выбор периферии и пользовательские настройки |
| `config.h` | Общие настройки, маска дешифратора и порядок катодов |
| `indication.h` | Порядок анодов индикаторов |
| `boards.h` | Собственные настройки платы для переноса на другие версии прошивки |

Для разводки, отличающейся от базовой платы автора прошивки, в документации Wiki используется `BOARD_TYPE 0`. Подробности — в [порядке настройки](CONFIGURATION.md).
