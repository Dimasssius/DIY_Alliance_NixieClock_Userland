## Порядок настройки прошивки

Для плат с разводкой, отличающейся от базовой прошивки, необходимо настроить подключение периферии и параметры индикации.

Основные файлы прошивки:

| Файл | Что настраивается |
| :--- | :--- |
| `connection.h` | Пины подключения периферии |
| `userConfig.h` | Выбор используемой периферии и тип платы |
| `config.h` | Маска дешифратора, порядок катодов и общие настройки |
| `boards.h` | Собственные настройки платы для удобного переноса на новые версии прошивки |
| `indication.h` | Порядок анодов индикаторов |

Рекомендуемый порядок:

1. Указать пины подключения периферии в `connection.h`.
2. Настроить используемую периферию в `userConfig.h` и `config.h`.
3. Выбрать тип платы в `userConfig.h` через `BOARD_TYPE`.
4. Для нестандартных плат использовать `BOARD_TYPE 0`.
5. Указать маску дешифратора и порядок катодов в `config.h`.
6. При необходимости настроить порядок анодов в `indication.h`.
7. По возможности перенести собственные настройки платы в `boards.h`, чтобы их было проще переносить на новые версии прошивки.
8. Собрать прошивку и загрузить ее в микроконтроллер.

## Порядок прошивки микроконтроллера

Для Arduino Nano-подобных плат с USB-UART на CH340G или CH340C может потребоваться установка драйвера CH340.

При прошивке через Arduino IDE:

1. Подключите Arduino Nano или плату с CH340 к компьютеру.
2. Дождитесь обнаружения устройства в системе.
3. В Arduino IDE выберите правильную плату.
4. Выберите COM-порт. Он должен отличаться от `COM1`.
5. Для многих Arduino Nano-клонов на ATmega328P нужно выбирать вариант с `Old Bootloader`.
6. Если прошивка не загружается, попробуйте обычный вариант bootloader или проверьте драйвер CH340.
7. Нажмите загрузку прошивки.

Arduino IDE поддерживает несколько вариантов прошивки. Стандартный способ - загрузка через USB-UART CH340. Также возможна прошивка через ISP-разъем, например программатором USBasp или USBtinyISP.

Если установлен новый ATmega328P и прошивка не загружается, возможно, на микроконтроллер сначала нужно записать bootloader программатором, а уже затем загружать скетч.

## Подбор катодной маски индикаторов

Катодная маска нужна, если в `config.h` нет готовой маски под выбранные индикаторы или цифры отображаются неправильно.

Инструмент находится здесь:

[Программа для подбора катодной маски](../tools/cathode-mask/)

Общий порядок:

1. Прошить часы с тестовой маской `999`.
2. После прошивки убедиться, что часы переходят в режим, пригодный для подбора катодов.
3. Запустить программу `Программа для подбора катодной маски.exe`.
4. Следовать инструкции внутри программы.
5. Получить последовательность катодов.
6. Указать полученную маску и порядок катодов в `config.h`.
7. Повторно прошить часы.
8. Проверить, что цифры от `0` до `9` отображаются корректно.

Порядок катодов конкретного индикатора можно искать в даташите на этот индикатор.

## Подбор порядка анодов

Порядок анодов задается в `indication.h`.

Подбор нужен, если катодная маска подобрана верно, но порядок индикаторов сбит. Например, вместо часов отображаются минуты или цифры стоят не на своих позициях.

Четкого универсального алгоритма нет: порядок анодов подбирается эмпирически. После каждого изменения прошивку нужно пересобрать, загрузить в часы и проверить результат.

Частые варианты порядка:

```cpp
ANODE_1_POS, ANODE_2_POS, ANODE_3_POS, ANODE_4_POS
ANODE_4_POS, ANODE_3_POS, ANODE_2_POS, ANODE_1_POS
ANODE_2_POS, ANODE_1_POS, ANODE_3_POS, ANODE_4_POS, ANODE_5_POS, ANODE_6_POS
ANODE_3_POS, ANODE_4_POS, ANODE_2_POS, ANODE_1_POS
```

В прошивке количество позиций анодов должно оставаться равным шести, даже если часы собраны на четыре индикатора:

```cpp
ANODE_1_POS, ANODE_2_POS, ANODE_3_POS, ANODE_4_POS, ANODE_5_POS, ANODE_6_POS
```

Для часов на четыре индикатора меняйте порядок только первых четырех анодов. Пятый и шестой анод не удаляйте.
